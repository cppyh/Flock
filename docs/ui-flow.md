# 화면 흐름

```text
홈 ─┬─ 그룹 만들기 ─┐
    ├─ 코드로 참여 ─┼─→ 대기실 ─→ 합류 추천 ─→ 주행 현황 ─→ 합류 완료
    ├─ 시연 모드 ───┘     ↑            │            │
    └─ 이어가기           └── 재추천 ───┴────────────┘
```

| 화면 | 파일 | 기획서 화면 |
|---|---|---|
| 홈 | `HomeScreens.kt` | 화면 1 |
| 그룹 만들기·참여 | `HomeScreens.kt` | 화면 2 |
| 대기실 | `LobbyScreen.kt` | 화면 2, 3 |
| 합류 추천 | `RecommendationScreen.kt` | 화면 4 |
| 주행 현황 | `DrivingScreen.kt` | 화면 5 |
| 합류 완료 | `DrivingScreen.kt` | 화면 6 |

화면은 그룹 단계에 따라 자동으로 바뀝니다. 다른 차량이 합류 장소를 확정하면 내 앱도 주행 현황으로 넘어갑니다.

## 차량 화면 규칙

| 규칙 | 구현 |
|---|---|
| 큰 터치 영역 | 버튼 높이 최소 76dp |
| 큰 글자 | 본문 18~20sp |
| 어두운 화면 | 야간 눈부심을 줄이는 다크 테마 |
| 가로 2단 배치 | 왼쪽 상태, 오른쪽 조작·지도 |
| 짧은 문구 | "총 우회 4분 / 최대 대기 21분" 형식 |

## 목적지 정하기

그룹장은 대기실에서 세 가지 방법으로 정합니다.

| 방법 | 동작 |
|---|---|
| 장소 이름이나 주소 입력 | "내비에서 검색"을 누르면 내비 검색 화면이 키워드와 함께 열립니다. 결과를 고르면 앱이 그룹 목적지로 가져옵니다 |
| 빠른 선택 | 강릉역 등 주요 여행지 6곳 |
| 내비 목적지 가져오기 | 내비에 이미 설정한 목적지를 가져옵니다 |

- 검색을 고르면 내비의 안내도 그 장소로 시작합니다. 내비의 동작입니다. 앱으로 돌아오려면 아래쪽 앱 아이콘을 누릅니다.
- 5분 안에 고르지 않으면 검색을 끝냅니다. 주행 중에는 골라도 정차할 때까지 그룹 목적지를 바꾸지 않습니다.
- 오프라인 시연 모드에서는 추천이 녹화 데이터라 검색과 드라이브 코스를 숨깁니다.

## 목적지 없이 드라이브

공통 목적지 칸 위의 "목적지 정하기 / 목적지 없이 드라이브"로 고릅니다.

| 설정 | 선택지 |
|---|---|
| 드라이브 시간(왕복) | 1~5시간, 1시간 단위. 서버가 ±15분 안의 코스를 무작위로 고릅니다 |
| 테마 | 바다, 숲길, 야경, 호수·강, 완전 랜덤 |
| 목적지 비공개 | 켜면 그룹원은 모두 합류할 때 목적지를 알게 됩니다 |

- "코스 추천받기"로 고르고, 마음에 들지 않으면 "다른 곳 추천"으로 이번 드라이브에서 보여 주지 않은 곳을 받습니다. 시간에 맞는 곳을 다 보여 줬으면 시간이 가장 가까운 다른 곳을 고르고 그 사실을 알립니다.
- 고른 코스는 일반 목적지와 같아서 이후 합류 추천·내비 등록 흐름이 그대로입니다.
- **비공개일 때 그룹원 화면:** 목적지 칸에 "비공개 목적지"와 테마·왕복 시간만 보입니다. 지도에 목적지를 그리지 않고, 추천의 목적지 후보도 "비공개 목적지"로 나옵니다. 내비에는 "내비에 합류 지점 등록"으로 합류 지점만 목적지로 넣습니다.
- **공개 순간:** 모든 차량이 합류 지점에 도착하면 모든 차량의 합류 완료 화면에 "오늘의 목적지"가 크게 뜨고 음성으로 "오늘의 목적지는 ○○입니다"라고 알립니다. 이어서 "목적지까지 그룹 이동 계속"으로 내비에 넣습니다.

## 전기차 표시

| 화면 | 표시 |
|---|---|
| 참여 차량 목록 | "배터리 45%" 칩. 20% 미만 빨강, 40% 미만 주황 |
| 추천 카드 | 이유 줄에 "충전 18분 중 12분 대기와 겹침", "충전소 없어 따로 충전 25분", "대기 중 충전 +15%" 중 하나. 정차 중에는 차량별 줄("수원: 도착 시 22% · 충전 5분, 대기 중 끝남")과 "충전기" 칩 |
| 주행 현황 | 내 전기차가 합류 지점에서 충전해야 하면 "기다리는 동안 약 18분 충전하세요" 배너 |
| 음성 | 내 전기차가 충전기 있는 합류 지점에 도착하면 "기다리는 동안 충전하세요. 약 18분 필요합니다." |

## 주행 중 제한

차량의 UX 제한 상태(`CarUxRestrictionsManager`)를 먼저 씁니다. 위치 공유와 상관없이 항상 알 수 있습니다. 이 상태를 읽을 수 없는 일반 Android에서만 위치 변화로 판단합니다(시속 약 5km 이상, 멈춘 뒤 10초가 지나야 정차).

| 기능 | 정차 중 | 주행 중 |
|---|---|---|
| 그룹 만들기·참여 | 가능 | 안내 문구만 표시 |
| 목적지·만남 목적 변경 | 가능 | 숨김 |
| 추천 상세 수치 | 표시 | 추천 이유만 표시 |
| 그룹 지도 | 표시 | 숨김, ETA 목록만 표시 |
| 세션 종료, 그룹 나가기 | 가능 | 숨김 |
| 위치 공유 끄기 | 가능 | 가능 |

## 안전 규칙

- 합류 장소 변경은 내비게이션에 자동 적용하지 않습니다. "내비에 경유지로 등록"을 운전자가 직접 누릅니다. 목적지에서 합류하면 버튼은 "내비에 목적지로 등록", 비공개 드라이브의 그룹원은 "내비에 합류 지점 등록"입니다.
- 내비가 다른 목적지로 안내 중이면 바꾸기 전에 묻습니다. "목적지를 바꾸고 등록"을 눌러야 공통 목적지로 바뀝니다. 내비가 경유지 좌표를 알려 주지 않아 운전자가 넣은 경유지는 지워질 수 있고, 화면에서 미리 알립니다.
- 그룹장이 합류 지점을 바꾸면 등록 상태를 지우고 다시 등록하라고 안내합니다. 이전 합류 지점을 등록된 것처럼 표시하지 않습니다.
- 재추천도 사용자가 요청할 때만 계산합니다. 지연이 감지되면 안내만 합니다.

## 위치 공유

- 공유 스위치는 대기실과 주행 현황 모두에 있습니다. 기획서 §9.1의 상시 공유 중지 때문입니다.
- 끄면 서버 응답을 기다리지 않고 수집부터 멈춥니다. 서버에 알리지 못하면 연결될 때 다시 보냅니다.
- Android 위치 권한 없이 Pleos 권한만 허용하면 앱이 화면에 있을 때만 공유하고 그 사실을 표시합니다. 위치 타입 포그라운드 서비스에 Android 권한이 필요하기 때문입니다.
- 전기차는 배터리 잔량도 함께 공유한다고 스위치 옆에 적습니다. 배터리 권한(`CAR_ENERGY`)을 거부하면 위치만 공유합니다.

## 그룹 지도

지도 타일 없이 차량, 합류 지점, 목적지의 상대 위치를 그린 개요도입니다. 지도 SDK의 차량 화면 표시 권한을 확인하기 전까지 이 방식을 씁니다. 기본 내비 화면 위에 마커를 올리는 기능은 지원이 확인되지 않아 쓰지 않습니다.
