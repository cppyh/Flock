# 휴게소 데이터

| 파일 | 내용 |
|---|---|
| `raw/한국도로공사_휴게소정보.csv` | 공공데이터포털 원본 |
| `rest_areas.csv` | 추천 엔진이 읽는 정리본 |
| `import_rest_areas.py` | 원본 → 정리본 변환 |

- **출처:** 한국도로공사, [전국휴게소정보표준데이터](https://www.data.go.kr/data/15025446/standard.do) (이용허락범위 제한 없음)
- **데이터 기준일:** 2026-09-17, 215곳
- **갱신 주기:** 반기. 새 파일을 `raw/`에 받은 뒤 `python data/import_rest_areas.py`를 실행한다.

## 알아 둘 점

- **방향은 이름의 괄호에서 읽는다.** `문막(강릉)`은 강릉 방향 휴게소다. 원본의 상행/하행 값은 일부 노선에서 뒤섞여 있어(중앙선 등) 쓰지 않는다.
- **괄호가 없는 14곳은 양방향 휴게소다.** 어느 방향에서나 들어갈 수 있다.
- **방향 도시 좌표**는 `import_rest_areas.py`의 표에 있다. 진행 방위각 계산에만 쓰는 대표 지점이다. 새 도시가 원본에 나오면 스크립트가 오류를 내므로 표에 추가한다.
- **운영 시각은 215곳 모두 00:00~23:59다.** 시설 내 식당의 실제 영업시간이 아니므로 심야 식사 추천에는 주의한다.
- **주차면수는 시설 규모이지 실시간 주차 가능 여부가 아니다.** 앱에도 데이터 기준일과 함께 표시한다.
- 데이터셋에 졸음쉼터는 없다. 간이휴게소(7곳)와 화물차휴게소(21곳)는 후보에서 뺀다.

# 드라이브 명소 데이터 (목적지 없는 드라이브)

| 파일 | 내용 |
|---|---|
| `drive_spots_seed.csv` | 사람이 고른 명소 목록. 이름, 테마, 지역, 검색어, 대략 좌표 |
| `drive_spots.csv` | 서버가 읽는 정리본. 좌표를 OpenStreetMap으로 확인한 100곳 |
| `build_drive_spots.py` | 대략 좌표 → OSM 검색 결과로 보정 |

- **좌표 출처:** © OpenStreetMap contributors, [ODbL](https://opendatacommons.org/licenses/odbl/). Nominatim 검색으로 대략 좌표에서 5km 안의 결과만 받아들였다. 앱이나 발표 자료에 이 데이터를 쓸 때 출처를 함께 밝힌다.
- **테마:** 바다 44, 야경 31, 숲길 26, 호수·강 21곳(한 곳이 여러 테마일 수 있다). 완전 랜덤은 전체에서 고른다.
- **사람이 고친 곳:** 호수 이름으로 찾으면 물 한가운데 좌표가 나와 내비로 갈 수 없다. 이런 곳은 댐 전망대·공원·관광단지 입구로 옮겼다(대청댐, 충주댐 대신 청풍호반 등). 5km 안에서 찾지 못한 8곳은 뺐다.
- **다시 만들 때:** `python data/build_drive_spots.py`. source가 OSM인 행은 그대로 두고 새 행만 찾는다. Nominatim 정책에 따라 1초에 한 번만 요청한다.
- **시간 맞춤 확인(2026-11-08, 서울 출발, OSRM 기준):** 5개 테마 × 1~5시간 25가지 중 22가지가 ±15분 안에 들었다. 나머지 3가지(야경 2·5시간, 호수 2시간)는 16~25분 차이로, 앱이 "가장 가까운 곳을 골랐다"고 알린다. OSRM은 교통 체증을 반영하지 않으므로 실제 주행은 더 걸릴 수 있다.
